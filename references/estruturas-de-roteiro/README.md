# Estruturas de Roteiro

Estruturas testadas para escrita de roteiros virais. Cada uma serve para um tipo diferente de vídeo.

## Estruturas disponíveis

| Estrutura | Etapas | Melhor para |
|---|---|---|
| [AIDA](aida.md) | Atenção > Interesse > Desejo > Ação | Vídeos de venda, conteúdo educativo com CTA |
| [IHC](ihc.md) | Identificação > História > Conteúdo | Conexão emocional, plantar ideias sem parecer venda |
| [Jeito Errado x Jeito Certo](jeito-errado-jeito-certo.md) | Conflito > Erro > Virada > Acerto > Mudança | Tutoriais, posicionamento de autoridade, contraste |
| [Ele, Eu, Você, Futuro](ele-eu-voce-futuro.md) | Ele > Eu > Você > Futuro | Storytelling compartilhado, narrativa que cresce |
| [Análise](analise.md) | Conflito > Resultados > 3 Motivos > Moral | Surfar tendências, analisar criadores, posicionar método |

## Como os agentes usam estas estruturas

- O **roteirista** sugere a estrutura mais adequada ao tema e objetivo do usuário
- O **analista-de-principios** identifica qual estrutura um vídeo analisado está usando
- O **crítico** verifica se a estrutura escolhida foi aplicada corretamente
